# Age Classifier

Java ile geliştirilmiş basit bir yaş sınıflandırma uygulaması.

## Projenin Amacı

Bu projenin amacı, kullanıcıdan alınan yaş bilgisini `if / else if / else` yapıları kullanarak belirli yaş gruplarına ayırmaktır.

Proje, Java'da temel seçim yapılarının ve kullanıcıdan veri alma işleminin uygulanmasını amaçlamaktadır.

## Kullanılan Teknolojiler

- Java
- Scanner
- if / else if / else

## Nasıl Çalışır?

Program kullanıcıdan yaş bilgisini alır ve girilen değere göre uygun yaş grubunu ekrana yazdırır.
